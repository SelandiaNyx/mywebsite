如何在 ArchLinux / ImmortalWrt 上使用 Docker 运行碧蓝航线脚本 ALAS

发布日期：2024/09/28

最近修改日期：2025/12/27

Arch Linux

  1. 安装 Docker 和 adb 
    sudo pacman -S docker docker-compose android-tools
  2. 启动 Docker 服务 
    sudo systemctl enable --now docker
  3. 将当前用户加入 docker 组（避免每次 sudo） 
    sudo usermod -aG docker $USER
newgrp docker
  4. 确保 adb 可用 
    waydroid status
adb connect waydroidIP:5555
adb devices
  5. 新建工作目录 
    mkdir alas-docker
cd alas-docker
  6. 获取 ALAS 源码 
    git clone https://github.com/LmeSzinc/AzurLaneAutoScript.git ~/alas-docker/src
  7. 创建 Dockerfile 
    touch Dockerfile
  8. Dockerfile 内容 
    FROM python:3.7-slim

# System dependencies
RUN apt-get update && apt-get install -y --no-install-recommends \
    wget git adb libgomp1 openssh-client ca-certificates \
    libgl1-mesa-glx libglib2.0-0 libsm6 libxext6 libxrender1 \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/*

# Install Miniconda
RUN wget -q https://repo.anaconda.com/miniconda/Miniconda3-py313_25.9.1-3-Linux-x86_64.sh \
    -O /tmp/miniconda.sh \
    && bash /tmp/miniconda.sh -b -p /opt/conda \
    && rm /tmp/miniconda.sh

ENV PATH="/opt/conda/bin:${PATH}"

RUN conda config --system --remove channels defaults \
    && conda config --system --add channels conda-forge \
    && conda config --system --set channel_priority strict

RUN conda install -y mamba

WORKDIR /app/AzurLaneAutoScript

COPY src/requirements.txt /tmp/requirements.txt

RUN AV_VERSION=$(grep -E '^av==' /tmp/requirements.txt | cut -d '=' -f 3) \
    && mamba install -y "python=3.7" "av==$AV_VERSION" \
    && conda clean --all --yes

RUN grep -v '^av==' /tmp/requirements.txt > /tmp/requirements_no_av.txt \
    && pip install --no-cache-dir -r /tmp/requirements_no_av.txt \
    && rm /tmp/requirements.txt /tmp/requirements_no_av.txt

CMD ["python", "gui.py"]
  9. 修改 requirements.txt

    注释以下内容：
    av==10.0.0
    pywin32==301

    并将 requests 调整为：
    requests>=2.20.0,<3

  10. 构建 Docker 镜像 
    docker build -t alas-conda .
  11. 创建 docker-compose.yml 
    touch docker-compose.yml
  12. docker-compose.yml 内容 
    services:
  alas:
    image: alas-conda
    container_name: alas
    network_mode: host
    volumes:
      - ~/.android:/root/.android
      - ./config:/alas/config
      - ./src:/app/AzurLaneAutoScript
    working_dir: /app/AzurLaneAutoScript
    command: python gui.py
  13. 运行 ALAS 
    docker-compose up

    后台运行： docker-compose up -d
    停止运行： docker-compose kill alas

至此，Arch Linux 环境配置完成。

ImmortalWrt

ImmortalWrt 的整体流程与 Arch Linux 基本一致，区别如下：

  • 软件安装使用 opkg install
  • 无 android-tools，使用 adb 包
  • 为节省空间，建议在 PC 上完成源码克隆与依赖修改

操作建议流程：

  1. 在电脑上克隆 ALAS 并修改 requirements.txt
  2. 将 src 目录打包为 src.tar.gz
  3. 上传至路由器并解压
  4. 在电脑上使用 socat 做端口转发： 
    socat TCP-LISTEN:5555,fork TCP:waydroidIP:5555
  5. 在 ALAS 中填写： 
    PCIP:5555

可选内容：修改反和谐

sudo waydroid shell
vim storage/emulated/0/Android/data/com.bilibili.azurlane/files/localization.txt

将 false 改为 true
