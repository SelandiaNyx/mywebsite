写心 · HeartWrite

Rust + Tauri 2 · 本地小说写作工作台

专门用来写长篇小说的桌面应用。卷章管理、人物剧情卡片墙、历史版本逐行对比、 一键排版、EPUB 导出——全部在本机完成。稿件不上传任何服务器，断网照写。

  • 7 套主题，正文可换任意系统字体，边调边预览
  • 自动快照 + 双栏逐行差异，误删也能回滚
  • EPUB / TXT / Markdown / HTML / JSON 五种导出
  • 单个 4 MB 的可执行文件，双击即用，无需安装

关于

写下自己的名字，也写下自己的工具

我是 SelandiaNyx，喜欢把「这事应该有现成的工具吧」变成「那我自己写一个」。 白天折腾 Linux 与网络，晚上写小说，于是就有了写心—— 因为市面上的写作软件要么在云上，要么太贵，要么根本不理解中文长篇的目录结构。

这里的项目大多始于自用。能用、够快、不打扰，是我对工具的全部要求， 也是这个站点连一个统计脚本都没有的原因。
